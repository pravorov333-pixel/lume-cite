# Lume Visuals — сайт клиента

Минималистичный сайт в стиле glass UI для клиента **Lume Visuals**.

## Что внутри

- **Главная** (`index.html`) — анимированный логотип и заголовок, возможности клиента (ПВП, Server Helper, ПВЕ, кастомизация), тарифы, ссылки на Telegram и TikTok.
- **Каталог** (`catalog.html`) — вкладки: партиклы, звуки, конфиги, косметика. Партиклы и конфиги — живой маркетплейс (см. ниже), звуки и косметика пока «In process».
- **Аккаунты и друзья** (`register.html`, `login.html`, `account.html`) — регистрация, вход, поиск игроков и заявки в друзья.
- **Маркетплейс** (`sell.html`, вкладки каталога) — любой пользователь может выставить свой конфиг/партикл на продажу за USDT; покупка подтверждается вручную.
- **Админка** (`admin.html`) — модерация объявлений и подтверждение оплат (доступна только аккаунтам с `is_admin = true`).
- Тёмная / светлая тема с сохранением выбора.
- Партиклы, реагирующие на курсор (фон + искры за курсором).

## Запуск локально

Сборка не нужна — это статический сайт. Из корня проекта:

```bash
# вариант 1: Python
python3 -m http.server 8000

# вариант 2: Node
npx serve .
```

Открой в браузере: http://localhost:8000

## Аккаунты, друзья и маркетплейс

Регистрация, друзья и продажа конфигов/партиклов работают через **Supabase**
(бесплатный backend-as-a-service: база данных + авторизация + хранилище файлов).
Оплата принимается вручную в **USDT (TRC20)** — без сторонних платёжных API.

### 1. Создай проект Supabase

1. Зайди на https://supabase.com → New Project (бесплатный план).
2. Дождись, пока проект поднимется (1–2 минуты).
3. Открой **SQL Editor** → New query, вставь содержимое файла
   `supabase/schema.sql` целиком и нажми Run.
   Это создаст таблицы (`profiles`, `friend_requests`, `listings`, `orders`),
   политики безопасности (RLS) и бакеты для файлов.

### 2. Подключи сайт к проекту

Открой **Project Settings → API**, скопируй `Project URL` и `anon public` key,
и вставь их в `js/supabase-config.js`:

```js
window.LUME_SUPABASE_URL = "https://xxxxxxxx.supabase.co";
window.LUME_SUPABASE_ANON_KEY = "eyJhbGciOi...";
window.LUME_USDT_WALLET = "твой-usdt-trc20-адрес";
```

Пока эти значения не заполнены, сайт работает как раньше (статические страницы),
а на страницах с аккаунтами/маркетплейсом показывается баннер «Бэкенд не подключён».

### 3. Сделай себя админом

После первой регистрации на сайте зайди в Supabase → **Table Editor → profiles**,
найди свою строку и поставь `is_admin = true`. Теперь тебе доступна `admin.html`.

### 4. Как проходит покупка (ручное подтверждение)

1. Покупатель жмёт «Купить» → создаётся заказ, показывается твой USDT-кошелёк и сумма.
2. Покупатель переводит USDT и вставляет хэш транзакции (TXID) в форму на сайте.
3. Ты (админ) заходишь в `admin.html`, проверяешь TXID в блокчейн-эксплорере
   (например tronscan.org для TRC20) и жмёшь «Подтвердить».
4. После подтверждения покупателю открывается скачивание файла в разделе
   «Мои покупки» (`account.html`).

Объявления на продажу проходят такую же ручную модерацию в `admin.html`
(вкладка «Объявления на модерации») — это защита от спама и скам-файлов,
так как продавать может любой зарегистрированный пользователь.

### Deploy

Сейчас сайт рассчитан на локальный запуск (`python3 -m http.server`).
Когда появится домен/хостинг — просто загрузи туда все файлы как есть,
ничего в коде менять не нужно (Supabase работает с любого домена, если он
указан в Project Settings → API → CORS/Site URL при необходимости).
