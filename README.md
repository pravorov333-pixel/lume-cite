# Lume Visuals — сайт клиента

Минималистичный сайт в стиле glass UI для клиента **Lume Visuals**.

## Что внутри

- **Главная** (`index.html`) — анимированный логотип и заголовок, возможности клиента (ПВП, Server Helper, ПВЕ, кастомизация), тарифы, ссылки на Telegram и TikTok.
- **Каталог** (`catalog.html`) — вкладки: партиклы, звуки, конфиги, косметика (пока «In process»).
- Тёмная / светлая тема с сохранением выбора.
- Партиклы, реагирующие на курсор (фон + искры за курсором).

## Запуск локально

Сборка не нужна — это статический сайт. Из корня проекта:

```bash
# вариант 1: Python
python3 -m http.server 8000

# вариант 2: Node
npx serve .
```

Открой в браузере: http://localhost:8000

## Структура

```
index.html      — главная страница
catalog.html    — каталог (партиклы / звуки / конфиги / косметика)
css/style.css   — стили, темы, glass UI
js/main.js      — тема, партиклы, анимации, вкладки каталога
assets/logo.svg — логотип
```

## Кастомизация цветов

Цвета клиента задаются в начале `css/style.css` в переменных:

```css
--accent:   #8b5cf6;  /* основной фиолетовый */
--accent-2: #22d3ee;  /* акцентный бирюзовый */
```
